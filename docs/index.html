Grimoire

A lightweight WoW addon manager

Browse, install, update, and remove your addons. No ads, no paywalls, no bloat. Free and open source.

Download View on GitHub

Available for macOS and Windows

Search & Browse

Search thousands of addons. One-click install downloads and extracts them directly to your AddOns folder.

Stay Up to Date

See which addons have new versions. Update them one at a time or all at once.

Multi-Version Support

Works with Classic Era, Cataclysm Classic, MoP Classic, and Retail. New game versions appear automatically.

Lightweight & Simple

Grimoire is a small, fast desktop app built with Tauri. No Electron bloat, no background processes, no telemetry. It does one thing and does it well.
